# RestaurantOS AI Foundation

This repository contains the architecture documentation and production foundation for RestaurantOS AI.

## Workflow

1. Read all docs.
2. Generate project foundation only.
3. Commit.
4. Build modules one by one.

## Current scope

Foundation only: monorepo, auth, multi-tenant RBAC, Prisma, Redis, Socket.IO gateway, shared UI/types, Docker, and CI.

Do not implement restaurant business modules until their dedicated phase.
