# Coding Standards

- TypeScript strict mode only
- No `any`
- Feature-first architecture
- Clean Architecture inside Nest modules
- SOLID principles
- Reusable components, hooks, services, DTOs, validation, utilities
- Tenant-safe queries
- Validate every API input
- Prefer simplicity over unnecessary abstractions
- Keep modules loosely coupled
- Production-ready only
- No mock data
- No placeholder code
- No TODO comments
- No demo pages
- Documentation and implementation must stay synchronized
