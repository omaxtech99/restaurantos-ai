# Design System

## Inspiration

Apple, Linear, Stripe, Vercel, Notion, Raycast.

## Style

- Premium and minimal
- Spacious layout
- Large, modern typography
- Responsive and mobile-first
- Light mode and dark mode
- Accessibility first
- Skeleton loaders, empty states, error states
- Smooth, purposeful motion
- Glassmorphism only where appropriate
- No outdated admin dashboard templates
- No clutter

## Foundation components

Button, Card, Dialog, Drawer, Table, Badge, Input, Toast, Skeleton, EmptyState, ErrorState.
